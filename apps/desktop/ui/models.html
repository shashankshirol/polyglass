Welcome to Polyglass

Polyglass reads the text under the lens and translates it on this computer. What you look at never leaves it.

Translation models

Models run on this computer. Polyglass downloads them only from the addresses it ships with and checks every file against its SHA-256 before using it.

Install from the repository

Install the Swedish ↔ English models once from a terminal in the Polyglass repository, then restart Polyglass:

About 170 MB of downloads and conversion; README → First run.

To translate between Swedish and English it needs two translation models. They are downloaded once from the Polyglass releases on GitHub. Nothing is downloaded until you choose Download.

Models to download

Swedish ↔ English is installed. Point the lens at Swedish or English text; ⇄ in the toolbar or Ctrl+Alt+S swaps the direction.

Download or delete models any time from ⚙ in the lens toolbar or “Translation models…” in the tray menu.
