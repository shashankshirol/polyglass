Welcome to Polyglass

Polyglass reads the text under the lens and translates it on this computer. What you look at never leaves it.

Translation models

Models run on this computer. Polyglass downloads them only from the addresses it ships with and checks every file against its SHA-256 before using it.

Install from the repository

Install the models once from a terminal in the Polyglass repository, then restart Polyglass:

The script downloads each model (about 290 MB) and converts it to about 85 MB; README → First run.

Models to download

Download or delete models any time from ⚙ in the lens toolbar or “Translation models…” in the tray menu.

    Import from a folder

    Have the model files already, e.g. downloaded from the Polyglass models release on another computer, or written by the install script? Enter their folder, or drop it on this window. Every file is checked against the catalog first.
