# Code of Conduct

Polyglass adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and inclusive, assume good faith, and focus on what's best for the
community. Harassment of any kind is not tolerated.
